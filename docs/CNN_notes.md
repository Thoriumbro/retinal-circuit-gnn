# **Convolutional Neural Networks (CNN)**

## **1. What is a CNN?**

A Convolutional Neural Network (CNN) is a type of Deep Neural Network
designed mainly for image processing. Unlike traditional machine
learning methods, CNNs automatically learn important visual features
such as edges, textures, shapes, and objects directly from pixel values.

CNNs are widely used in:

-   Image Classification

-   Object Detection

-   Face Recognition

-   Medical Imaging

-   Autonomous Vehicles

-   Satellite Image Analysis

## **2. Why CNNs?**

Traditional Artificial Neural Networks (ANNs) become inefficient when
working with images because every pixel must connect to neurons in the
next layer.

For example, a 224 × 224 image contains over 50,000 pixels, resulting in
millions of parameters.

Challenges include:

-   High memory usage

-   Slow training

-   Overfitting

-   Loss of spatial information

CNNs solve these problems by learning local patterns using small filters
instead of processing every pixel independently.

## **3. Core Idea Behind CNNs**

CNNs mimic how humans recognize objects.

When viewing a face, humans first identify simple features:

-   Edges

-   Corners

-   Eyes

-   Nose

-   Mouth

Similarly, CNNs learn features hierarchically:

-   Early layers learn edges

-   Middle layers learn textures and shapes

-   Deep layers learn complete objects

This process is called **hierarchical feature learning**.

**4. Image Representation**

A digital image is represented as a matrix of pixel values.

Example:

1 2 3\
4 5 6\
7 8 9

For color images, three channels are used:

-   Red (R)

-   Green (G)

-   Blue (B)

Image size is represented as:

**Height × Width × Channels**

Example:

224 × 224 × 3

## **5. Convolution Operation**

The main operation in a CNN is **Convolution**.

A small matrix called a **Filter** or **Kernel** slides across the
image.

Example Filter:

1 0\
0 1

At each position:

1.  Multiply corresponding values

2.  Add the results

3.  Store the output

The output is called a **Feature Map**.

Convolution helps detect useful patterns while keeping the number of
parameters low.

## **6. Feature Maps**

Different filters learn different visual patterns.

Examples:

-   Vertical edges

-   Horizontal edges

-   Diagonal edges

-   Curves

-   Textures

The outputs generated by these filters are called **Feature Maps**,
which contain important image information.

# How do we know feature map size?

Formula: Output= ((Input−Filter)/Stride)+1

## **7. ReLU Activation Function**

After convolution, CNNs apply an activation function. The most common
activation function is **ReLU (Rectified Linear Unit)**.

Formula:

ReLU(x) = max(0, x)

Examples:

-   ReLU(7) = 7

-   ReLU(-3) = 0

Benefits:

-   Introduces non-linearity

-   Improves learning

-   Reduces computation

-   Helps model complex patterns

## **8. Pooling Layers**

Pooling reduces the size of feature maps while preserving important
information. The most common method is **Max Pooling**.

Example:

Input:

4 8\
2 6

Output:

8

Benefits:

-   Reduces memory usage

-   Speeds up computation

-   Reduces overfitting

-   Preserves important features

## **9. CNN Architecture Pipeline**

A typical CNN follows this sequence:

Input Image\
↓\
Convolution Layer\
↓\
ReLU\
↓\
Pooling Layer\
↓\
Convolution Layer\
↓\
ReLU\
↓\
Pooling Layer\
↓\
Flatten Layer\
↓\
Fully Connected Layer\
↓\
Output Layer

This architecture is commonly used for image classification tasks.

## **10. Flattening and Classification**

After convolution and pooling, feature maps are converted into a
one-dimensional vector.

Example:

Feature Map:

1 2\
3 4

Flattened Vector:

\[1, 2, 3, 4\]

The vector is passed to Fully Connected Layers for classification.

Example Output:

-   Cat = 0.95

-   Dog = 0.03

-   Horse = 0.02

Prediction: **Cat**

## **11. CNNs and Graph Data**

CNNs assume data has a fixed structure, such as images where neighboring
pixels are predictable.

Graphs do not have fixed neighborhoods:

-   Some nodes may have 1 neighbor

-   Others may have 100 neighbors

Because of this irregular structure, CNNs cannot directly process graph
data. This limitation led to the development of **Graph Neural Networks
(GNNs)**.

import torch

import torch.nn as nn

import torch.nn.functional as F

import torchvision

import torchvision.transforms as transforms

import matplotlib.pyplot as plt

device = torch.device(\'cuda\' if torch.cuda.is_available() else
\'cpu\')

print(\"Running on:\", device)

\# \-\-\-\-- Real data, already split into TRAIN and TEST \-\-\-\--

transform = transforms.Compose(\[

transforms.ToTensor(),

transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5)),

\])

train_set = torchvision.datasets.CIFAR10(

root=\'./data\',

train=True,

download=True,

transform=transform

)

test_set = torchvision.datasets.CIFAR10(

root=\'./data\',

train=False,

download=True,

transform=transform

)

train_loader = torch.utils.data.DataLoader(

train_set,

batch_size=64,

shuffle=True

)

test_loader = torch.utils.data.DataLoader(

test_set,

batch_size=64,

shuffle=False

)

classes = \[

\'airplane\',

\'automobile\',

\'bird\',

\'cat\',

\'deer\',

\'dog\',

\'frog\',

\'horse\',

\'ship\',

\'truck\'

\]

print(\"Data ready. Train:\", len(train_set), \"\| Test:\",
len(test_set))

\# \-\-\-\-- The CNN (6 steps) \-\-\-\--

class SimpleCNN(nn.Module):

def \_\_init\_\_(self):

super().\_\_init\_\_()

self.conv1 = nn.Conv2d(

in_channels=3,

out_channels=8,

kernel_size=3

) \# 32-\>30

self.pool = nn.MaxPool2d(

kernel_size=2

) \# 30-\>15

self.fc1 = nn.Linear(

8 \* 15 \* 15,

10

) \# 1800 -\> 10

def forward(self, x):

x = self.conv1(x) \# 1) Convolution

x = F.relu(x) \# 2) ReLU

x = self.pool(x) \# 3) Max pool

x = x.view(x.size(0), -1) \# 4) Flatten -\> 1800-vector

x = self.fc1(x) \# 5) Fully connected -\> 10 scores

return x \# 6) Softmax handled by the loss during training

model = SimpleCNN().to(device)

criterion = nn.CrossEntropyLoss()

optimizer = torch.optim.Adam(

model.parameters(),

lr=0.001

)

\# \-\-\-\-- TRAINING: the 8 epochs happen here \-\-\-\--

print(\"\\n=== TRAINING (8 epochs) ===\")

EPOCHS = 8

for epoch in range(EPOCHS):

model.train()

running_loss = 0

correct = 0

total = 0

for images, labels in train_loader:

images = images.to(device)

labels = labels.to(device)

optimizer.zero_grad()

outputs = model(images)

loss = criterion(outputs, labels)

loss.backward()

> optimizer.step()

running_loss += loss.item()

correct += (outputs.argmax(1) == labels).sum().item()

total += labels.size(0)

print(

f\"Epoch {epoch+1}/{EPOCHS} \| \"

f\"Loss: {running_loss/len(train_loader):.3f} \| \"

f\"Train Acc: {100\*correct/total:.1f}%\"

)

\# \-\-\-\-- TESTING on unseen images \-\-\-\--

print(\"\\n=== TESTING on unseen images ===\")

model.eval()

correct = 0

total = 0

with torch.no_grad():

for images, labels in test_loader:

images = images.to(device)

labels = labels.to(device)

print(

f\"Test Accuracy on {total} unseen images: \"

f\"{100\*correct/total:.1f}%\"

)

### **Explanation of the CNN Implementation**

This CNN implementation uses the CIFAR-10 dataset, which contains 60,000
color images belonging to 10 classes such as cat, dog, airplane, ship,
etc. The input to the model is a 32×32 RGB image (3 channels). During
training, the image first passes through a Convolution layer that
extracts visual features, then a ReLU activation layer that removes
negative values, followed by Max Pooling which reduces image size while
preserving important features. The resulting feature maps are flattened
into a 1D vector and passed through a Fully Connected layer that
generates 10 output scores, one for each class. The model is trained for
8 epochs using Cross Entropy Loss and the Adam optimizer. After
training, the CNN predicts the class of unseen test images or
user-uploaded images by selecting the class with the highest
probability.

Input:

-   CIFAR-10 color image

-   Image size: 32 × 32 pixels

-   Channels: 3 (RGB)

-   Input tensor shape: \[3, 32, 32\]

Output:

-   A vector of 10 scores corresponding to the 10 classes:\
    \[airplane, automobile, bird, cat, deer, dog, frog, horse, ship,
    truck\]

-   Softmax converts these scores into probabilities.

-   The class with the highest probability is selected as the final
    prediction.

Example Output:\
Cat = 82%\
Dog = 10%\
Horse = 3%\
Others = 5%

Final Prediction = Cat

### **Conclusion**

-   Increased the number of filters in the first convolution layer from
    **8 to 32** to extract more image features.

-   Added a **second convolution layer (64 filters)** to learn more
    complex patterns from the images.

-   Increased the **batch size from 64 to 128** for faster and more
    stable training.

-   Improved the **test accuracy from 59.1% to 74.5%**, demonstrating a
    significant improvement in performance.

### **Reason for Accuracy Saturation**

-   The CNN architecture is still relatively **shallow**, containing
    only two convolution layers.

-   A shallow network has **limited feature extraction capability**,
    making it difficult to learn highly complex image patterns.

-   CIFAR-10 is a **challenging dataset** with large variations in
    object appearance, background, scale, and orientation.

-   After sufficient training, the model reaches its **architectural
    capacity**, so increasing epochs alone provides little or no
    improvement.

-   Achieving **90%+ accuracy** typically requires **deeper CNN
    architectures**, additional convolution blocks, batch normalization,
    residual connections (e.g., ResNet), or transfer learning.
